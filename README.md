# Content Studio

소셜 콘텐츠용 슬라이드쇼와 영상을 만들고, 검증된 템플릿을 재사용해 꾸준히 제작하기 위한 로컬 작업 공간입니다. 에이전트와 함께 콘텐츠를 작성하고 시각 편집기에서 결과를 확인·수정한 뒤 게시용 이미지나 영상으로 내보냅니다.

## 슬라이드 편집

텍스트·이미지·도형·배경을 편집하고 여러 장의 구성을 함께 관리합니다. 공통 요소를 공유해 일관된 디자인을 유지하면서 각 장의 내용과 배치를 조정할 수 있습니다. 프로젝트를 저장해 이어서 작업하고, 완성된 슬라이드는 PNG ZIP으로 내보냅니다.

## 영상 편집

영상을 이어붙이거나 여러 운동 영상을 한 화면에 배치하고, 텍스트·이미지·도형과 음악을 함께 편집합니다. 시간축에서 자르기·분할·순서와 표시 시간을 조절하고, 캔버스에서 위치·크기·회전·색상을 바꿀 수 있습니다. AI가 텍스트·도형·미디어와 타임라인을 편집하고 여러 시점의 미리보기를 확인할 수 있습니다. 사용한 미디어와 편집 내용을 프로젝트에 저장하고, 완성한 영상은 MP4로 내보냅니다. MP4를 불러와 기존 영상 뒤에 이어붙이거나 독립 요소로 배치할 수 있습니다. 편집기 열기에서 슬라이드쇼와 영상을 선택하고 유형별 프로젝트를 이어서 작업합니다.

## 템플릿 재사용

완성한 프로젝트에서 필요한 페이지를 선택해 독립 템플릿으로 만들고 새로운 콘텐츠의 출발점으로 사용합니다. 템플릿은 선택한 페이지의 내용과 이미지를 복사해 별도로 보관하므로, 자유롭게 수정해도 원본 게시글에 영향을 주지 않습니다. 구성 설명은 재사용 가능한 전달 목적과 시각적 구조를 안내합니다. 원본의 시각적 구조와 자산을 활용해 주제와 내용을 바꾸며 제작 시간을 줄입니다. 완성된 프로젝트에서 게시 완료를 등록하면 달력과 목록에서 게시 이력을 확인할 수 있습니다.

## 에이전트와 협업

에이전트와 함께 콘텐츠를 작성하고, 시각 편집기에서 결과를 확인하고 다듬습니다. 콘텐츠 기획부터 편집과 내보내기까지 같은 프로젝트를 중심으로 작업합니다.

## 콘텐츠 리서치

더 좋은 내용과 새로운 전달 방식을 찾기 위해 실제 플랫폼의 게시물을 조사합니다. 다른 계정의 본문과 슬라이드, 반응 지표를 살펴 콘텐츠의 소재와 설명 방식을 얻고 새로운 포맷을 실험할 때 참고합니다. 에이전트는 제작 목적에 맞춰 필요한 자료를 수집하고 확인합니다.

## 콘텐츠 제작

제작 개수를 정하면 이전 기록과 레퍼런스를 분석하고 콘텐츠별로 병렬 제작합니다. 노드를 눌러 단계별 진행 내용을 확인하고, 저장된 포스트를 편집기로 열 수 있습니다. 제작 모델은 화면 하단에서 선택하며, 공개 게시물의 성과와 실제 게시 모습을 이후 제작에 활용합니다.
