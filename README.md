# Content Studio

로컬에서 슬라이드를 편집하고 PNG ZIP으로 내보내는 시각 편집기입니다. 콘텐츠 기획·생성은 외부에서 진행하며, 앱은 Codex CLI를 실행하거나 AI 채팅을 제공하지 않습니다.

## 사용

```sh
pnpm install
pnpm dev
```

http://127.0.0.1:3000 에서 ‘편집기 열기’를 누르면 4:5 (1080 × 1350), 6장의 빈 문서가 바로 열립니다. 구성·언어 설정 화면은 없습니다. 화면 비율은 편집기 상단에서, 슬라이드 수는 추가·삭제로 변경합니다. 저장된 프로젝트도 대시보드에서 바로 불러올 수 있습니다.

## 편집

- 텍스트·이미지·도형·배경을 직접 편집합니다.
- Element 정의를 여러 장에서 공유하며, 선택한 장에만 위치·스타일을 적용할 수 있습니다.
- 슬라이드와 레이어 순서를 드래그로 변경합니다.
- 이미지를 캔버스에 드롭하거나 이미지 에셋에서 선택합니다.
- 프로젝트 저장에는 시각 문서와 사용 이미지가 포함됩니다. 대화·제안·AI 쓰레드는 없습니다.
- ZIP 내보내기는 프로젝트를 자동 저장하고 슬라이드별 PNG를 생성합니다.

## 경계

AI 제안·라우팅·편집 API, 레퍼런스 분석, 제품 컨텍스트 및 Codex 연결·모델 설정은 제거했습니다. 수동 편집·되돌리기·저장·업로드·내보내기·대시보드에 필요한 HTTP 엔드포인트와 문서 검증은 유지합니다.

외부 이미지 폴더 경로는 앱에서 고정하지 않습니다. 외부 Codex에서 만든 문서를 파일로 연결하는 규칙 및 불러오기 기능은 아직 구현하지 않았습니다.

## 데이터

SQLite 기본 위치는 프로젝트 상위 워크스페이스의 `content-studio.sqlite`입니다. 이미지 바이트와 메타데이터, 저장 프로젝트를 SQLite에서 관리합니다. 이번 정리는 DB 스키마나 기존 데이터를 변경하지 않습니다.
