# Content Studio

소셜 콘텐츠용 슬라이드를 만들고, 검증된 템플릿을 재사용해 꾸준히 제작하기 위한 로컬 작업 공간입니다. 에이전트와 함께 콘텐츠를 작성하고 시각 편집기에서 결과를 확인·수정한 뒤 게시용 이미지로 내보냅니다.

## 슬라이드 편집

텍스트·이미지·도형·배경을 편집하고 여러 장의 구성을 함께 관리합니다. 공통 요소를 공유해 일관된 디자인을 유지하면서 각 장의 내용과 배치를 조정할 수 있습니다. 프로젝트를 저장해 이어서 작업하고, 완성된 슬라이드는 PNG ZIP으로 내보냅니다.

## 템플릿 재사용

완성한 프로젝트를 템플릿으로 등록해 새로운 콘텐츠의 출발점으로 사용합니다. 템플릿의 구성 설명은 에이전트가 전달할 정보에 맞는 포맷을 선택하는 데 도움을 줍니다. 원본의 시각적 구조와 자산을 활용해 주제와 내용을 바꾸며 제작 시간을 줄입니다.

## 에이전트와 협업

에이전트와 함께 콘텐츠를 작성하고, 시각 편집기에서 결과를 확인하고 다듬습니다. 콘텐츠 기획부터 편집과 내보내기까지 같은 프로젝트를 중심으로 작업합니다.

## 콘텐츠 리서치

더 좋은 내용과 새로운 전달 방식을 찾기 위해 실제 플랫폼의 게시물을 조사합니다. 다른 계정의 본문과 슬라이드, 반응 지표를 살펴 콘텐츠의 소재와 설명 방식을 얻고 새로운 포맷을 실험할 때 참고합니다. 에이전트는 제작 목적에 맞춰 필요한 자료를 수집하고 확인합니다.
