# Spy 주제 패턴 관찰

2026-11-04 저장 자료의 세 계정을 모두 조사했다. [게시물별 근거 목록](spy-topic-corpus.csv)에 167개 게시물의 캡션·게시 시각·표지 OCR·기존 본문 설명을 남겼다. Arrow 29개, Bluebro 110개, Obsidian 28개다. 슬라이드쇼 149개는 표지와 본문 이미지를 확보했다. Arrow·Bluebro는 표지와 첫 본문, 캡션이 모호한 Obsidian은 전체 슬라이드를 읽어 총 421개 이미지의 문구를 확인했다. 슬라이드 이미지가 없는 18개는 캡션만 확인했으며 영상 내용·시각 구성의 증거로 사용하지 않는다. OCR에는 철자 오류가 있을 수 있어 아래 핵심 사례는 이미지와 대조했다. 이 표본은 계정 전체 역사나 균등한 기간의 표본이 아니다.

## 관찰한 생성 방식

주제는 부위 이름 하나가 아니라 **대상 × 독자가 해결할 질문 × 적용 상황**의 조합으로 만들어진다. 아래는 관찰된 방식이며 생성기의 고정 카테고리나 강제 비율이 아니다.

| 독자의 질문 | 실제 사례 | 전개에서 유지되는 역할 |
| --- | --- | --- |
| 무엇을 고를까? | Arrow `7703164506951666974` 종아리 운동 비교, `7698759052762844446` 어깨 운동 순위 | 대안과 평가 근거, 선택의 결론 |
| 어떻게 조합할까? | Arrow `7703910536035028254` 상체 운동 선택, Bluebro `7631839259737066760` 푸시데이 구성 | 필요한 역할별 대안, 조합 규칙 |
| 그대로 무엇을 실행할까? | Obsidian `7648248747008232726` 덤벨 홈트, `7642483564524670230` 등 운동 | 구체 동작, 수행량, 실행 설명 |
| 내 일정에 어떻게 맞출까? | Arrow `7697433039214857503` 주당 빈도별 분할, `7704148391034375454` 4일 분할 비교 | 시간 조건, 일정 구성, 대안의 차이 |
| 무엇을 고치거나 이해할까? | Arrow `7700916044633787679` 벤치프레스 교정, Bluebro `7633998963858869511` 점진적 과부하, `7690396916651281716` 휴식 시간 | 문제·원리, 이유, 적용 행동 |

같은 대상에 다른 질문을 붙이기도 하고, 같은 질문을 다른 대상·조건으로 확장하기도 한다. 예를 들어 어깨는 순위·운동 선택·실행 루틴으로, 분할은 주당 횟수별 선택·특정 횟수의 비교·완성된 일정으로 나타난다. ‘어깨 3종목’을 ‘등 3종목’으로 바꾸는 것만이 확장이 아니다.

## 계정별 차이

- Arrow는 순위·평가와 역할별 운동 선택이 두드러지며, 일정·교정도 다룬다. 같은 순위 전개를 근육군과 주당 빈도로 확장한다.
- Bluebro는 순위·운동 선택·루틴·훈련 원리·실수·영양으로 범위가 넓다. 같은 주제를 다른 독자의 질문으로 다시 다룬다. 캡션의 부가 홍보 문구를 본문 주제로 오인하면 안 된다.
- Obsidian은 기구·장소·부위 조건을 붙인 실행 안내와 분할, 운동 도감이 두드러진다. ‘다음 운동 때 저장’ 같은 캡션만으로는 주제가 구분되지 않아 실제 표지가 필요했다.

단순 게시물 수 비례로 합치면 Bluebro가 전체 167개 중 110개를 차지한다. 그렇다고 세 계정의 생성 비중을 무조건 같게 만들 근거도 없다. 공통 패턴과 계정별 차이를 추출하고 제품·독자에게 맞는 후보를 만든다.

## 생성기에 적용할 판단

- 후보는 구체적인 대상·독자의 질문·답변 방식·유용한 조건을 가진다. 서로 다른 문구나 부위 이름만으로 다양한 후보라고 판단하지 않는다.
- spy 사례는 후보 확장의 근거다. 외부 반응률을 우리 예상 성과로 사용하거나, 기존 내부 레이아웃에 넣기 쉬운지를 후보 선정 근거로 삼지 않는다.
- 우리 게시글과 연결할 때 대상과 독자의 질문이 같은 직접 사례, 질문만 비슷한 간접 사례를 구분한다. 간접 사례의 성과를 직접 검증으로 계산하지 않는다.
- 순위의 단정·과장된 최적 표현·키 성장·호르몬 증가 같은 원문의 주장은 사실 검증 없이 계승하지 않는다. 독자의 질문은 활용하되 답은 근거에 맞게 작성한다.
- 후보 분포를 다양하게 만드는 것은 실제 게시 성과가 좋아졌다는 증명이 아니다. 합성 DB는 분류·선정·캐시·재개 동작을, 실제 게시 결과는 효과를 검증한다.
