# Swolo 같은 캐릭터 운동 영상의 제작 방식

조사일: 2026-11-06. 사용자가 Swolo처럼 짧은 캐릭터 운동 영상을 우선 검토하며, 실제 3D 모델링인지와 유사 포맷의 제작 방법을 질문했다.

## 확인한 사실과 확인하지 못한 것

- [Swolo 플랭크 TikTok](https://www.tiktok.com/@swolotips/video/7682703510764260621)에 `Contains AI-generated media` 표시가 실제로 있다. AI 사용을 나타내지만 어떤 프로그램·단계에 사용했는지는 알려주지 않는다.
- [월엔젤](https://www.tiktok.com/@swolotips/video/7684690335829724430)과 [월싯](https://www.tiktok.com/@swolotips/video/7690621129156742414)을 재생해 운동 자세, 신체 부위 확대, 해부학 그림, 기간 표시, 큰 자막을 조합한 편집 구조를 확인했다.
- 월싯은 약 35.5초의 한 루프를 재생하며 표본 장면을 확인했다. 월엔젤은 전반부 연속 재생과 추가 장면 확인을 병행했다. 재생은 음소거 상태였으므로 내레이션 원문이나 음성 생성 도구를 확인했다고 주장하지 않는다.
- [공식 소개](https://swolotips.com/about/)는 캐릭터 외형과 주차별 설명 구조를 공개하지만 이미지 생성기·영상 모델·편집기·3D 제작 도구는 공개하지 않는다.
- 실제 3D 메시와 리그의 존재, 이미지→영상 생성 사용 여부, AI와 3D를 결합한 비중은 확인하지 못했다. 입체감과 캐릭터 일관성만으로 사용 도구를 판별하지 않는다.

따라서 정확한 분류는 **AI 사용 표시가 있는 3D풍 캐릭터 영상, 상세 제작 과정 미확인**이다. 아래는 동일한 종류의 결과를 만들기 위한 제안이며 Swolo의 비공개 제작 과정을 복원한 사실이 아니다.

## 유사 포맷을 만드는 현실적인 작업 순서

1. **대본·음성·장면 구성을 먼저 정한다.** 약 30~40초의 한 질문에 답하도록 설계하고, 운동 동작·신체 설명·기간 전환 등 장면 역할을 나눈다.
2. **독자적인 캐릭터 기준 이미지를 만든다.** 정면·측면·후면, 체형·얼굴·의상·색·조명을 정한다. 이후 장면은 이 기준 이미지를 참조한다. 이는 3D 모델 파일이 아니라 이미지들이다.
3. **장면별 완성 이미지를 준비한다.** 운동하는 전신, 손목·어깨 등의 확대, 내부 구조 설명 장면을 각각 만든다. 자막과 숫자는 원본 이미지에 포함하지 않고 편집 단계에서 배치한다.
4. **움직임이 필요한 장면만 짧게 영상화한다.** 이미지→영상 모델에 기준 프레임과 동작 지시를 준다. 예를 들어 고정 카메라에서 팔을 천천히 올리는 한 동작을 요청한다. 정적인 설명 장면은 확대·이동 같은 편집만 적용할 수 있다. 몇 초씩 만들고 필요한 길이만 잘라 조합하는 것은 제안하는 제작 방식이다.
5. **음성에 맞춰 컷·자막·강조 표시를 편집한다.** 기간 표지, 핵심 단어, 화살표, 효과음을 별도로 다루면 수정하기 쉽다. 입이 없는 캐릭터라면 입 모양을 음성에 동기화할 작업이 줄어든다.
6. **동작과 설명을 검수한다.** 손·발 접촉, 관절 경로, 기구의 움직임, 캐릭터 외형의 변화를 확인한다. 해부학 그림은 입체적으로 보인다는 이유로 정확하다고 간주하지 않는다.

## 공식 문서로 확인한 구현 수단

| 목적 | 가능한 수단 | 확인한 기능 |
| --- | --- | --- |
| 동일 캐릭터의 장면 이미지 | [Runway Gen-4 Image References](https://help.runwayml.com/hc/en-us/articles/40042718905875-Creating-with-Gen-4-Image-References) | 캐릭터·사물·스타일 참조 이미지로 다른 장면 생성 |
| 이미지를 짧은 영상으로 | [Runway Image to Video](https://help.runwayml.com/hc/en-us/articles/48324313115155-Image-to-Video-Prompting-Guide) | 입력 이미지가 구도·스타일·피사체를 제공하고 프롬프트는 동작을 설명 |
| 참조 이미지·시작/끝 장면 활용 | [Google Veo](https://deepmind.google/models/veo/) | 캐릭터 참조, 첫 프레임·마지막 프레임을 이용한 생성 |
| 실제 동작을 캐릭터에 전달 | [Wan2.2 Animate](https://github.com/Wan-Video/Wan2.2) | 캐릭터 이미지와 동작 참조 영상을 받아 캐릭터 동작 생성 |
| 컷·음성·자막 합성 | [CapCut](https://www.capcut.com/resource/ai-video-editor-guide) | 타임라인 편집, 오디오·텍스트, 자동 자막과 수동 조정 |

이 도구 목록은 구현 예시다. Swolo가 이 도구들을 사용했다는 증거는 없다. 기능 지원은 해당 운동 동작의 생성 품질을 검증한 결과가 아니다.

## 운동 동작을 만드는 두 경로

- 간단한 움직임: 캐릭터의 올바른 시작 자세 이미지 + 이미지→영상 동작 지시.
- 관절 경로가 중요한 움직임: 캐릭터 이미지 + 사용 권한이 있는 동작 참조 영상. 생성 결과에는 캐릭터가 등장하도록 구성할 수 있다. 참조 경로를 써도 결과의 접촉·관절 움직임은 확인해야 한다.

첫 제작 검증은 캐릭터 이미지와 한 동작의 3~5초 클립으로 진행하는 것을 제안한다. 이미지 일관성과 동작이 확인되면 여러 컷을 조합한 짧은 설명 영상으로 확장한다. 이번 조사에서는 유료 생성·모델 설치·영상 제작을 실행하지 않았다.
