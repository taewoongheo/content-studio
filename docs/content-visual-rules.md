# 공통 시각 규칙

모든 자동 제작에서 이 문서를 읽는다. 내용에 맞게 정보 구조와 배치를 만들며, 템플릿 선택은 필수 단계가 아니다.

- 독자가 바로 사용할 답을 중심으로 구성한다. 훅에서 얻을 가치를 보여주고 본문이 약속한 답을 제공한다.
- 이미지와 짧은 텍스트로 전달한다. 설명을 늘리기 전에 비교·묶음·순서 같은 시각적 전달을 검토한다.
- 최근 자체 게시글과 좋은 레퍼런스의 실제 이미지를 보고, 깔끔한 정렬·여백·정보 위계·가독성을 유지한다.
- 배경은 흰색으로 하고 실제 지원 글꼴과 편집 명령을 사용한다. 공통 스타일을 공유하는 요소는 같은 Element 정의를 사용한다.
- 모든 장을 이미지로 확인한다. 잘림·겹침·낮은 대비·어색한 문구·누락 이미지를 수정하고 다시 확인한다.
- 사실·효과·수치 주장은 docs/content-guidelines.md의 근거 기준을 따른다. 레퍼런스 성과를 운동 효과의 근거로 쓰지 않는다.
