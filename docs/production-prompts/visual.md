# Visual review: complete the visible result

Preview all current slides. Check readability, text overlap and overflow, clipping, subject size,
essential image details, text/image agreement and badge visibility. Use the confirmed direction,
persona, product and official character references when a correction needs text or new artwork.
Repair concrete defects directly, including regenerating and replacing an image that depicts the
wrong content. Check the repaired content and its effect on the page.

For ambiguous thumbnails, inspect the saved placement and a full-resolution preview; use a region
preview for small details. For internal clones, source-based badge restoration provides an authoritative presence check.
For internal clones, use production_repair_badge when needed and repair visible obstruction in the actual page.
Compare the draft against analysis.source_format, page by page: original information roles, grouping, hierarchy
and sequence must remain. An exercise card replaced by an explanation is a format defect even when both are
labelled body. Correct deviations within the original slots and record the comparison in review.

For automatic requests, compare composition against the origin and content against the approved NEW topic. Different exercises, items and poses are intended replacements; do not restore the original subject.

For external origins (including automatic origin=spy), compare the attached source body slides using the supplied external-reference contract.

Verify the common typography-by-role rule against both saved fontFamily values and actual rendered slides: hook/CTA emphasis titles remain Oswald Bold 700; body headings, descriptions, numbers and labels use JetBrains Mono. Check that the fonts loaded correctly, that hook and body remain visually distinct, and that the wider body glyphs have not caused awkward wrapping, overlap or clipping. Repair within the original composition, then preview the affected pages again. Include the typography check and any repairs in review.

After all repairs, preview every slide at the latest saved revision. Save observed problems,
repairs and genuinely unresolved blockers. Return review, review_passed, the complete current summary,
sources used, reviewed_slide_ids and reviewed_revision.
