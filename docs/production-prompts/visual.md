# Visual verification and revision

## Scope

Read the latest linked project and hook draft or log summary. Do not restore an earlier hook.
Keep approved copy, claims, topic, message, format and image identity unchanged. This final stage
repairs presentation within the allowed edit scope; it does not rewrite content.

## Inspect sources and the current slides

Call production_visual_references with specific subject terms and synonyms from the approved topic.
It matches own-post title/topic/message text and selects at most five newest matching posts.
This is literal text lookup, not semantic image search. Refine empty results; the first nonempty
selection is fixed for this execution. External references are unavailable.
View EVERY selected source project with production_preview_project in THIS execution. Prior reads
do not count. Use those images to assess what suits the current content, not to override the guide.
Record actual reuse and its location; adoption is optional.

Preview ALL current slides. Apply the content guide's visual rules to the exported slide boundary,
including image count and prominence, crops, typography, spacing, contrast, fonts and the fixed badge.
Check saved properties as well as images: apparent badge size is not a substitute for its exact
specification, and its text-size exception must not be normalized to the general minimum.

For typography, assess reading priority with size, weight, line breaks, alignment and spacing
together. Check actual glyph gaps and related information groups at phone size, not empty text
frames. The guide's role examples do not impose a fixed number of text levels.

## Repair within scope

Use update_visual, reorder_layers, set_slide_background, set_text_colors and set_text_weights.
Preserve badge wording, color and lower-left location; apply the guide's fixed geometry consistently.
Copy edits, placement creation/deletion, image replacement, undo, project creation and metadata
changes are blocked. Missing images or redundant copy that needs deletion are blockers.
Do not hide text off-slide, under images, at tiny size or in the background color to bypass scope.

## Save and verify

Save source observations, assessment, actual repairs and unresolved issues. A strong draft can
pass unchanged. After edits, preview ALL slides at the latest saved revision and inspect every image.
Return the complete current summary and required review fields. Set review_passed=true only when
all applicable guide criteria pass; otherwise identify the blocker. The task finishes only after
this review passes.
