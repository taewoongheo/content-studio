# External URL and saved external reference contract

Start from a blank project with production_create_project, using the confirmed plan's slide count.
Do not select or clone an internal project. On resume, keep and repair the already linked project,
including a draft created under an older workflow.

## Preserve the external body; apply our identity

Keep the source subject, verified substance, body progression, page roles and information roles.
Preserve body layout relationships: grouping, alignment, relative hierarchy, text/image placement,
and how information is represented. A star rating stays stars; a day-by-day table keeps its columns
and rest cells. Replacing either with a numeric badge or a loose row of figures loses information.
Adapt dimensions to 4:5 and readable English without redesigning that structure. Do not reproduce
platform UI, search bars, navigation arrows, watermarks or the reference account's branding.

Use our visual language: white (#FFFFFF) slide background, black (#000000) main text, red (#FF0000)
text emphasis, and gray secondary text. Use selective bold/color on meaningful words instead of
copying the external highlight bars, palette or decorative type treatment. Body text, headings,
numbers and labels use Inter; body text is at least 35px at 1080px slide width. Keep source body
hierarchy and alignment while changing these styles. Generate new illustrations with the attached
official character references; preserve their identity while matching the source's information role,
pose/action and placement. External character images are composition evidence, not identity references.
Use real transparent artwork, editable text and shapes; do not paste source screenshots as slides.

## Our hook and CTA

Create the hook's wording AND visual composition in our own style, grounded in the actual body promise
and persona voice. Do not preserve the external cover layout. Use an uppercase Oswald Bold 700 title,
110–140px, black with selective red emphasis; at most one optional Inter 35px #B0B5BE supporting phrase.
Make the official character illustration prominent and arrange a coherent, vertically centered group
with clear spacing. CTA uses our typography and the selected product's facts and CTA, subject to user
instructions. Never carry over the reference account's product, handle, logo or badge.

usable content; in presentation, identify source page roles and body layouts to retain, including
information representations and necessary content corrections. Specify what changes for our style,
hook and product CTA. Distinguish factual corrections from design adaptation. Do not add a separate

clone_project_id=null.

Production receives all source slides with the official identity references. Implement presentation

user request can justify a difference. Do not restore an internal clone badge in this workflow.
