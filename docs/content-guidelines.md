# 슬라이드 생성과 재사용 지침

이 문서는 Codex가 Content Studio에서 게시용 슬라이드를 생성·수정할 때 지키는 제약이다. Content Studio 앱 자체의 UI 디자인에는 적용하지 않는다.

## 복제 후 유지와 변경의 범위

- **기본적으로 유지:** 훅·본문의 폰트와 스타일, 카드 모양, 정렬과 간격, 계정 뱃지 등 원본의 시각적 규칙. 별도 요청 없이 새로 디자인하지 않는다.
- **이번 주제에 맞춰 교체:** 훅 문구, 본문, 이미지, 운동 정보, 제목, 캡션과 해시태그. 이전 게시글의 내용이 남지 않도록 확인한다.
- **필요할 때 조정:** 페이지와 카드 수, 요소 추가·삭제, 정보량 변화로 생긴 넘침과 잘림을 해결하는 크기와 배치. 기존 스타일을 활용하고 변경 범위를 최소화한다.
- 요소를 추가할 때는 기존의 비슷한 역할을 가진 요소의 스타일을 활용한다. 다른 포맷에 필요한 요소를 추가한다는 이유로 전체 스타일을 바꾸지 않는다.
- 사용자가 제공한 자산과 참조 범위를 지킨다. 필요한 이미지가 없으면 이전 주제의 이미지를 새 콘텐츠의 이미지처럼 남기거나 다른 이미지로 조용히 대체하지 않는다. 누락을 표시한다.

## 공통 규칙과 우선순위

이번 작업에 대한 사용자의 명시적 요청을 가장 먼저 따른다. 그다음 아래 공통 고정 규칙을 적용하고, 나머지 시각적 규칙은 선택한 템플릿에서 유지한다. 템플릿의 설정이 공통 규칙과 충돌하면 충돌하는 부분만 수정한다. 사용자가 고정 규칙의 예외를 명시했다면 그 예외는 이번 작업에만 적용한다.

- **고정 규칙:** 모든 슬라이드 페이지의 배경은 흰색 `#FFFFFF`이다. 이미지 내부 배경이나 정보 구분용 강조 영역까지 흰색으로 바꿀 필요는 없다.
- **고정 규칙:** 사실, 연구 결과, 해석, 커뮤니티의 경험을 구분한다. 근거가 허용하는 수준보다 강하게 단정하지 않는다.
- **고정 규칙:** 훅의 약속은 본문에서 뒷받침한다. 효과를 과장하거나 관심을 끌기 위해 불안을 만들어내지 않는다.
- **기본값:** 훅은 독자가 얻을 이득이나 피할 손해를 구체적으로 드러내어 감정을 건드린다. 맞지 않는 경우 궁금증·공감·안도감 등으로 계속 읽을 이유를 제시할 수 있다.

## 조사와 근거의 제약

- 과학적·수치적 주장을 새로 만들거나 바꾸면 필요한 근거를 조사한다. 검증된 기존 근거는 주제 적합성과 최신성을 확인한 뒤 재사용할 수 있다.
- 연구와 신뢰할 수 있는 원문을 우선 확인하고 대상, 비교 조건, 측정 결과가 게시할 주장과 맞는지 판단한다. 검색 요약만으로 강한 주장을 확정하지 않는다.
- 커뮤니티는 반복되는 고민, 사용 상황, 반론, 실제 공감 언어를 찾는 데 활용한다. 댓글과 개인 경험을 효과의 과학적 증거로 취급하지 않는다.
- 한 사람의 표현을 전체 사용자의 의견으로 일반화하지 않는다. 출처나 사용자 반응을 지어내지 않는다.
- 근거가 약하거나 충돌하면 주장을 좁히거나 제외한다. 핵심 주장과 출처의 연결은 작업 메모 또는 최종 설명에 남긴다.
- 색상·크기·배치만 수정할 때 관련 없는 새 조사를 반복하지 않는다.

## 결과 검토의 제약

지침을 읽었다는 사실이나 도구의 성공 응답만으로 완료를 판단하지 않는다.

- 모든 페이지의 배경과 시각적 속성을 확인한다. 원본에서 물려받아야 할 훅·본문·계정 뱃지 스타일이 불필요하게 바뀌지 않았는지 확인한다.
- 모든 페이지를 미리보기로 확인한다. 글자 넘침, 잘림, 겹침, 대비, 이미지 크기와 비율을 확인한다. 이미지는 각 슬롯의 영역에 맞춰 조정하며 하나의 크기를 일괄 적용하지 않는다.
- 필수 정보, 흐름, 훅과 본문의 일치, 주장과 근거의 연결을 확인한다.
- 문법, 모호한 표현, 반복 의미, 용어 일관성, 제목·캡션·해시태그의 정합성을 확인한다.
- 표현은 미국인, 틱톡에서 자연스러운 표현으로 작성. AI 티가 나지 않도록 자연스러운 표현으로 작성하였는지, 표현이 어색하진 않은지 체크한다.
