# 콘텐츠 메타데이터 작성 기준

내부 게시글과 외부 레퍼런스에 같은 기준을 적용한다. 저장하는 값은 영어로 작성한다.

| 항목 | 필드 | 작성할 내용 |
| --- | --- | --- |
| 소재 | `topic` | 무엇을 다루는가. 운동 대상·상황·질문 등 구체적인 범위를 적는다. |
| 메시지 | `message` | 실제로 전달하는 핵심 내용이나 독자에게 제공하는 답을 적는다. 훅 문구나 제작 이력을 대신 넣지 않는다. |
| 포맷 | `content_type` | 정보를 조직하고 보여주는 구조를 자연어로 설명한다. 페이지 전개·정보 묶음·넓은 시각적 구조를 포함한다. |

포맷은 고정 목록에서 선택하지 않는다. 순위 비교, 선택지 비교, 운동별 설명, 한 장에 모은 루틴 등은 예시다. 소재나 문구가 달라도 구조가 비슷하면 같은 계열로 판단할 수 있다. 특정 운동명이나 세트 수로 포맷을 지나치게 좁히지 않는다.

정확한 좌표·이미지 크기·글꼴·색상·여백은 슬라이드 원본이 담당한다. 포맷에 세부 스타일이나 재현 명령을 나열하지 않는다. 실제 표현을 판단할 때는 원본 슬라이드를 확인한다.

## 예시

| 항목 | 예시 1 | 예시 2 |
| --- | --- | --- |
| 소재 | Biceps exercise selection | At-home ab workout |
| 메시지 | Compare thirteen biceps exercises to help readers choose for their equipment and preferences. | Provide four ab exercises with sets, repetitions and rest periods for a home session. |
| 포맷 | A tier chart that groups exercises into ranked rows. | A separate card for each exercise, followed by a full-routine summary. |

예시는 작성 방식을 설명한다. 실제 슬라이드가 다른 구조라면 그 구조를 적는다.

## 작성 시점과 책임

- **분석 및 제작 방향:** 만들 콘텐츠의 예정 소재·메시지·포맷을 정한다.
- **초안 제작과 최종 완성:** 실제 슬라이드와 일치하는지 확인하고, 단계 결과의 요약에 세 항목을 모두 포함한다. 서버는 같은 메타데이터를 프로젝트와 제작 로그에 함께 반영한다.
- **새 외부 레퍼런스:** 수집 코드는 원본 캡션·성과·이미지를 보존한다. 해당 CLI가 실제 슬라이드를 확인한 뒤 `production_describe_reference`로 소재·메시지·포맷과 식별용 제목을 저장한다. 별도의 저장용 CLI는 실행하지 않는다.
- **외부 자료 재사용:** 메타데이터는 탐색을 위한 요약이다. 원본에서 다른 내용을 확인하면 수정한다. 내용 확인에 실패했다면 값을 만들지 말고 미확인 상태를 남긴다.

미확인 외부 자료와 기존 게시글의 빈 값은 읽을 수 있지만, 메타데이터를 새로 작성·수정하거나 제작 단계를 완료할 때는 세 필드를 모두 채운다. 원본 캡션·성과·URL은 이 세 필드와 별도로 보존한다.

성과 분석은 소재를 넘어서 비슷한 포맷을 묶어 비교한다. 최근 중복 검사는 소재와 포맷을 함께 비교한다. 자연어 표현의 일치 여부가 아니라 실제 구조의 유사성을 에이전트가 판단하며, 단순 문자열 일치를 중복 판정으로 사용하지 않는다.
