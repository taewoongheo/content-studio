# 콘텐츠 메타데이터 작성 기준

내부 게시글과 외부 자료에 같은 기준을 적용하며 영어로 저장한다.

- `topic` — 무엇을 다루는가: 설명할 구체적인 대상·소재.
- `message` — 그 대상에 관해 독자에게 실제로 전달할 답.
- `content_type` — 독자의 질문 유형, 답변 방식, 각 정보의 역할과 전개 순서. 대상 이름이나 세부 디자인과 분리해 자연어로 적는다.

소재 변형은 설명 대상을 바꾸되 같은 자리에서 같은 정보 역할을 유지하는 것이다.
단순히 같은 칸에 들어가거나 장 수가 같은 것으로 포맷이 같다고 판단하지 않는다.
같은 대상의 설명 관점만 바꾸거나 기존 칸에 다른 종류의 설명을 넣는 것은 이 제작의 변형 기준이 아니다.
좌표·크기·서체·강조 등 시각 구성은 원본 문서가 담당한다.

분석은 소재·답·포맷을 확정하고 presentation에 원본 정보 역할과 새 내용의 대응을 기록한다.
후속 단계는 승인된 포맷을 그대로 전달한다. 실제 결과의 요약에도 세 필드를 포함한다.
외부 자료의 미확인 값은 추정하지 않는다. 메타데이터는 탐색 요약이며 실제 내용은 원본으로 확인한다.
최근 중복은 소재와 포맷의 의미를 비교하며 단순 문자열 일치로 판단하지 않는다.
