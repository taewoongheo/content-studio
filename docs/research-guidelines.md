# 콘텐츠 리서치 기준

리서치는 콘텐츠에 쓸 소재·설명 방식·근거를 얻거나 새로운 전달 방식을 실험하기 위해 진행한다. 먼저 이번 조사로 얻으려는 것과 대상 주제·계정을 정하고 필요한 수집 도구를 선택한다. 콘텐츠 제작마다 리서치를 수행할 필요는 없다.

## 레퍼런스 선별 (임시 기준)

- 이번 콘텐츠의 주제와 관련된 게시물을 찾는다.
- 기본 형식은 슬라이드쇼로 한다.
- 조회수 100,000 이상을 확인한다. 좋아요 하한은 아직 정하지 않는다.

사용자가 이번 요청에서 지정한 조건이 우선한다. 이 기준은 추후 사용자와 조정한다. 내용의 사실적 근거를 조사하는 경우에는 레퍼런스의 조회수와 별개로 해당 주장에 대한 근거를 확인한다.

## 확인 방법

- 선별 조건을 수집 요청에 전달하고 결과에서 충족 여부를 확인한다. 주제 관련성은 본문과 필요한 슬라이드 이미지를 직접 읽고 판단한다.
- 원본이 제공하지 않는 조회수·저장 수 등은 `null`이다. 이를 추정하거나 0으로 바꾸지 않는다. 필수 수치를 확인할 수 없으면 조건을 충족한 후보로 확정하지 않는다.
- 반응 수는 수집 시점의 값이다. 축약 표시된 수치는 원본 표시도 확인하며, 반응 수를 내용의 사실성이나 운동 효과의 근거로 취급하지 않는다.
- 댓글 본문·답글은 수집하지 않는다. 게시물의 댓글 수만 반응 지표로 사용한다.

## 결과에 남길 것

- 참고한 게시물의 출처와 수집 시점, 이번 콘텐츠에 활용할 소재나 설명 방식을 남긴다.
- 선별 기준의 충족·미충족·미확인을 구분한다. 확인하지 못한 값이나 조사에 실패한 범위도 함께 설명한다.
- 사실적 주장을 작성할 때는 그 주장을 뒷받침하는 근거를 별도로 확인한다.

도구 사용법과 수집 실패 시 처리 방법은 [AGENTS.md](../AGENTS.md)의 콘텐츠 리서치 작업 안내를 따른다.
