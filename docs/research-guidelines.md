# 콘텐츠 리서치 기준

소재·훅·표현 방식은 과거 게시글과 사용자가 직접 지정한 선별 레퍼런스에서 참고하고 개선한다. 에이전트가 외부 TikTok·Instagram 게시글이나 소셜 피드를 검색해 새 소재·포맷·시각 레퍼런스를 찾지 않는다. 사용자가 외부 게시글을 직접 레퍼런스로 등록한 경우에는 그 지정 자료를 확인할 수 있다.

## 필요한 질문이 있을 때 조사한다

리서치는 분석·제작 중 현재 콘텐츠를 만드는 데 필요한 질문이 생겼을 때 진행한다. 매번 실행하는 필수 단계가 아니며, 조사 항목을 모두 채울 필요도 없다.

예를 들어 다음과 같은 질문을 조사할 수 있다.

- 운동 효과·수치·과학적 주장을 작성하는데 근거가 부족하다면 원문 논문이나 공식 자료를 확인한다.
- 논문에서 다루지 않는 세팅·장비·수행상의 불편이나 대처 방법이 궁금하다면 관련 커뮤니티의 구체적인 경험을 살펴본다.
- 타겟이 문제·상황·원하는 결과를 실제로 어떻게 표현하는지 알고 싶다면 커뮤니티의 질문·후기·대화를 확인한다.

이 예시는 조사 범위를 세 종류로 제한하거나 종류별 기록을 요구하는 기준이 아니다. 그 밖에도 이번 내용에 필요한 질문이라면 상황에 맞춰 조사한다. 소재·표현 레퍼런스를 외부에서 새로 발굴하는 용도로 확대하지 않는다.

기존 로그나 지정 레퍼런스에 필요한 출처가 있다면 적합성을 확인해 재사용한다. 검색어는 답하려는 질문에서 정하고, 과거 검색어를 그대로 반복하지 않는다. 질문에 답할 자료를 확보하면 조사를 마친다.

## 자료를 해석하는 기준

- 논문은 대상·운동 경험·장비·비교 조건·측정 결과가 작성할 주장과 맞는지 확인한다. 검색 요약만 보고 결론을 확정하지 않는다.
- 커뮤니티 팁은 적용 상황과 사용자의 경험으로 다룬다. 논문이 없다는 이유로 배제하지 않지만, 경험담을 과학적으로 검증된 운동 효과로 바꾸지 않는다. 팁에 효과·안전성 주장이 붙으면 해당 부분의 근거를 따로 확인한다.
- 공감 언어는 실제 표현과 출처를 확인한다. 한 사람의 표현을 전체 사용자의 요구로 일반화하지 않는다. 필요한 짧은 표현을 참고하고 개인 식별 정보는 가져오지 않는다.
- 조회수·좋아요는 사실성, 팁의 효과 또는 타겟의 공통 요구를 증명하지 않는다. 외부 게시물의 반응 수를 리서치 선별 기준으로 삼지 않는다.
- 사실, 연구 결과, 경험담, 에이전트의 해석을 구분한다. 근거가 부족하거나 충돌하면 주장을 좁히거나 제외하고, 확인하지 못한 부분을 남긴다.
- 소재·시각적 표현을 참고하는 지정 레퍼런스도 그 안의 효과 주장을 자동으로 보증하지 않는다.

## 조사 결과에 남길 것

기존 단계 draft의 research에 답하려던 질문·실제로 확인한 출처 URL·발견한 내용·이번 콘텐츠에 반영할 판단을 남긴다. 별도의 조사 종류 필드는 두지 않는다.

활용한 출처는 sources에도 연결한다. 조사로 제작 방향을 바꾸면 변경 이유를 남긴다. 실패한 조사나 확인하지 못한 결과를 성공한 것처럼 기록하지 않는다.
