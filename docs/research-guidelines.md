# 콘텐츠 리서치 기준

소재는 과거 게시글의 성과·실제 내용과 인터넷·커뮤니티 조사를 함께 보고 고른다. 훅·시각적 표현은 과거 게시글과 사용자가 지정한 선별 레퍼런스를 참고한다.

## 소재를 찾는 조사

- 일반 웹 검색과 커뮤니티의 질문·후기·대화에서 타겟이 원하는 결과, 막히는 상황, 반복해서 찾는 답을 살핀다.
- 우리 계정에서 잘된 소재가 왜 유용했는지와 연결해, 이번에 제공할 답의 후보를 만든다. 반응이 낮았던 소재를 표현만 바꿔 재사용하는 것으로 후보를 한정하지 않는다.
- 중량 조절 같은 특정 문제나 과거 검색어에 계속 머물지 않는다. 타겟의 다른 욕구·일정·장비·경험에서 필요한 답도 탐색한다.
- 서로 다른 소재·제공 가치의 후보를 비교하고, 독자에게 필요한 이유와 이번 콘텐츠에서 완성해 줄 답을 기준으로 선택한다.
- 검색 요약만으로 사용자 반응을 단정하지 않는다. 판단에 사용하는 원문과 실제 표현을 확인하고 출처 URL을 남긴다.
- TikTok·Instagram 내부 검색이나 피드 탐색으로 새 게시글·시각 레퍼런스를 수집하지 않는다. 사용자가 지정한 게시글은 확인할 수 있다.

## 제작 중 필요한 조사

주제를 정한 뒤에도 표현·실행 조건·장비 사용 등 필요한 질문이 생기면 상황에 맞게 조사한다. 매번 같은 종류의 자료를 채우거나 모든 항목을 조사할 필요는 없다. 기존 자료로 충분하면 다시 찾지 않는다.

## 해석과 기록

- 실제 확인한 내용, 개인의 경험, 에이전트의 해석을 구분한다. 한 사람의 말을 전체 타겟의 요구로 일반화하지 않는다.
- 공감 언어는 실제 표현과 출처를 확인한다. 필요한 짧은 표현만 참고하고 개인 식별 정보는 가져오지 않는다.
- 출처에 없는 효과·수치·사용자 반응을 만들지 않는다. 확인할 수 없는 주장은 범위를 좁히거나 제외한다.
- 조회수나 좋아요만으로 소재의 유용성이나 내용의 정확성을 단정하지 않는다. 어떤 사람이 어떤 답을 원했는지 맥락을 함께 본다.
- 각 단계 draft의 research에 질문·출처 URL·발견한 내용·이번 판단을 기록한다. 실제 사용한 자료는 sources에도 연결한다.
- 조사로 제작 방향을 바꾸면 변경 이유를 남긴다. 실패한 조사나 확인하지 못한 자료를 성공한 것처럼 기록하지 않는다.
